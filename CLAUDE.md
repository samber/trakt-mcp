# trakt-mcp

## Purpose

- Remote, multi-tenant MCP server exposing user's Trakt account (catalog, watchlist, history, collection, ratings, check-ins, recommendations, smart lists) to Claude and ChatGPT.
- OAuth 2.1 authorization server toward MCP clients (ory/fosite); confidential OAuth client toward Trakt (API v2).
- One Go binary, one SQLite file, exactly one instance. Trakt data (history, watchlist, ratings...) never touches disk.
- Module `github.com/samber/trakt-mcp`, binary `trakt-mcp`, `go 1.26` in `go.mod`, `CGO_ENABLED=0`.

## Package map

- `cmd/trakt-mcp`: subcommands `serve`, `genkey`, `rekey`, `disconnect <trakt slug or numeric trakt id>`, `version`; wiring.
- `internal/config`: flags plus unprefixed env (flag name uppercased, dashes to underscores), per-command required values.
- `internal/crypto`: rotatable AES-256-GCM keyring (`keyid:base64`).
- `internal/jobs`: per-minute flush of batched `last_seen_at` (`Store.Close` flushes too), hourly expired-row cleanup.
  - Daily purge of users inactive 180 days: delete rows first, then revoke at Trakt; guarded against reconnects.
  - Purge of clients unused 180 days or never used after 24 h.
- `internal/limits`: per-user read/write token buckets (burst = per-minute count), global Trakt budget bucket, per-user write lock.
- `internal/oauth`: authorization server: metadata, CIMD, DCR, consent, Trakt callback (`/oauth/trakt/callback`), token, revoke. HTML in `templates/`.
- `internal/obs`: Prometheus metrics (namespace `trakt_mcp`), per-call tool logging.
- `internal/store`: SQLite store, embedded migrations (`migrations/001_init.sql`), fosite storage, users and encrypted Trakt tokens.
- `internal/trakt`: hand-written wrapper.
  - `client.go`: headers, timeouts, retries, pagination; error kinds in `errors.go`.
  - `upstream.go`: OAuth exchange, single-use refresh, revoke, profile.
  - `api/`: code generated by `oapi-codegen` from `openapi.filtered.json`. Never edit by hand.
  - `gen/filterspec`: filters Trakt's official OpenAPI file down to `endpoints.txt`, applies overlay patches.
- `internal/tools`: MCP server and tools. Tool table in `registry.go` (plus `catalog.go`); one file per area.
- `internal/web`: HTTP mux (MCP, OAuth), `GET /` redirect to `--site-url`, `GET /.well-known/openai-apps-challenge` (only with `--openai-apps-challenge`), metrics basic auth. Renders no page.
- `plugin/openai/`: ChatGPT/Codex plugin package (`plugin.json`, `mcp.json`, icon); `make plugin-openai` zips it into `dist/trakt-openai-plugin.zip`. Submission steps for it and for the Claude connector: `docs/directory-submission.md`.
- `site/`: Astro website (landing page, privacy policy, terms) for the hosted instance; own gates and rules in `site/CLAUDE.md`.

## Gates

Run all before every commit. `Makefile` has no `gofmt` or `vet` target; run those directly.

```sh
gofmt -l .                                              # must print nothing
go vet ./...
make lint                                               # golangci-lint run
make test                                               # go test -race -v ./...
go generate ./internal/trakt/api && git diff --exit-code internal/trakt   # generated client not stale
```

- Run `make generate` after editing `internal/trakt/endpoints.txt` or the overlay; commit `openapi.filtered.json` and `api/api.gen.go` together. `make spec-fetch` refreshes the cached upstream spec in `$TMPDIR`.
- Run `make plugin-openai` whenever anything in `plugin/openai/` changes, or a tool name, title or description changes. Bump `version` in `plugin/openai/plugin.json` first: OpenAI rejects a changed package with an old version.
- Change the tool count in one test only (`TestRegistryHas<N>Tools`); keep README, plugin and site lists in sync.

Other `make` targets: `build`, `coverage` (writes `cover.out`, `cover.html`), `bench`, `watch-test`, `watch-bench`, `tools`, `lint-fix`, `audit`, `outdated`, `weight`. `generate`, `spec-fetch` and `plugin-openai` are described above.

## CI and automation

- `.github/workflows/test.yml`: push to `main` and PRs; matrix Go `go.mod` + `stable`; checks the generated Trakt client offline (`go generate` + `git diff`), then `make build`, `make test`, `make coverage`, Codecov upload.
- `.github/workflows/spec-drift.yml`: weekly cron + manual; reruns `make generate` against Trakt's live OpenAPI file, fails on diff. Never on PRs.
- `.github/workflows/lint.yml`: push to `main`, PRs, weekly cron, manual; `golangci-lint-action` with `.golangci.yml`.
- `.github/workflows/security.yml`: push to `main`, PRs, weekly cron, manual; Bearer, CodeQL, two Trivy jobs. `govulncheck` job commented out.
- `.github/workflows/release.yml`: manual dispatch with a `semver` input (owner only); runs `make test`, tags, creates a GitHub release. Publishes no binary and no Docker image.
- `.github/workflows/dependabot-automerge.yaml`: auto-merge (squash) of Dependabot `github_actions` PRs only.

## Domain jargon

- **Trakt slug**: URL id of a show, movie, person or user (`breaking-bad`). Tools also take the numeric **Trakt id** and the **IMDb id** (`tt…` titles, `nm…` people). Episodes have no slug.
- **`trakt-api-key`**: header carrying the app client id on every call, beside `trakt-api-version: 2`.
- **Single-use refresh**: every Trakt refresh returns a new refresh token and kills the old one.
  - Refresh runs under a per-user lock; new pair written before unlock.
  - Only `invalid_grant` discards the stored token (and deletes the user).
- **420 / 423 / 426**: Trakt account limit reached / account locked / VIP required. Surfaced verbatim, never retried.
- **VIP**: paid Trakt tier; raises list, watchlist, collection caps; needed for watchlist notes.
- **Scrobble**: media-center playback reporting. Out of scope. **Check-in**: manual "watching now"; 409 returns the active one.
- **Collection**: media the user owns. **Watchlist** (singular in Trakt enums): to watch later. **History**: watched plays.
- **Smart list**: Trakt saved filter list; 2 tools shipped, live behavior unverified (spec 17).
- **Codegen pipeline**: `endpoints.txt` -> `filterspec` (+ overlay) -> `openapi.filtered.json` -> `oapi-codegen` -> `api/api.gen.go`. Patch the filtered spec, never generated code.
- **CIMD**: Client ID Metadata Document. `client_id` is `https://` URL; server fetches JSON (SSRF guard, 5 s, 64 KiB, cached up to 24 h, served stale max 7 days, dropped on 404/410/400).
- **DCR**: Dynamic Client Registration (RFC 7591), `POST /oauth/register`, public clients only, `--enable-dcr`.
- **PKCE**: S256 only, toward clients and toward Trakt.
- **RFC 9207 `iss`**: issuer parameter added to every authorization response.
- **RFC 8707 `resource`**: must equal `<base-url>/mcp`; tokens get that audience. Scope is `trakt`.
- **RFC 9728**: protected-resource metadata at `/.well-known/oauth-protected-resource` and `/.well-known/oauth-protected-resource/mcp`.
- **Network volume**: the SQLite file may sit on a mounted network filesystem, so journal mode is DELETE, not WAL. No replication or backup ships with the project.

## Conventions

- Env vars unprefixed (`--db-path` -> `DB_PATH`); secrets env only: `ENCRYPTION_KEYS` (required), `TRAKT_CLIENT_SECRET` (optional; Trakt deprecated it for PKCE, omitted from requests when empty).
- Never log tool arguments or results above `debug`. Never log tokens, codes, secrets, request URLs or Trakt response bodies.
- Branch on `*trakt.Error` `Kind`, never on its message. Use `ConflictBody()` for the 409 check-in payload.
- Treat comment text and other third-party strings as untrusted; bound them with `boundText`.
- No magic numbers or strings inline: named constants, each with one-line "why" comment.
- Never ignore error. Structured `slog` logging.
- User deletion runs explicit `deleteUserChildren` list (`internal/store/users.go`); add every new per-user table to it.
- Every tool needs a `title` and explicit `readOnlyHint`, `destructiveHint`, `openWorldHint`: Claude's and OpenAI's directories reject tools without them (`TestToolAnnotations`).
- Flags must stay in sync with the configuration table in `docs/self-hosting.md` and spec section 13.
- Conventional Commits.
