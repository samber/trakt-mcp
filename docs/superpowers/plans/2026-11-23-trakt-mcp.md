# trakt-mcp Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Convert the repository from a Google Contacts MCP server into a Trakt MCP server (80 tools), including website, spec, CLAUDE.md, README and plugin package.

**Architecture:** Keep the fosite OAuth authorization server, SQLite store, AES-GCM keyring, limits, jobs, obs and web layers. Replace `internal/google` + `internal/contacts` with `internal/trakt` (client generated by `oapi-codegen` from a filtered copy of Trakt's OpenAPI file, wrapped by hand) and rebuild `internal/tools` on a table-driven registry.

**Tech Stack:** Go 1.26, ory/fosite, modelcontextprotocol/go-sdk v1.8.0, `modernc.org/sqlite`, `oapi-codegen` (pinned as a `tool` in `go.mod`), Astro (`site/`).

**Spec:** `docs/superpowers/specs/2026-11-23-trakt-mcp-design.md`

## Global Constraints

- Module `github.com/samber/trakt-mcp`, `go 1.26` in `go.mod`, `CGO_ENABLED=0`, binary `trakt-mcp`, command dir `cmd/trakt-mcp`.
- Env vars carry **no prefix**: each flag reads the env var of the same name, uppercased, dashes to underscores (`--db-path` / `DB_PATH`). Secrets env-only: `TRAKT_CLIENT_SECRET`, `ENCRYPTION_KEYS`. Flag `--trakt-client-id` / `TRAKT_CLIENT_ID`.
- Gates before every commit, in order: `gofmt -l .` prints nothing, `go vet ./...`, `make lint`, `make test` (`go test -race -v ./...`). Never weaken `.golangci.yml`.
- No magic numbers or strings inline: named constants with a one-line "why" comment. Never ignore an error. Structured `slog`.
- Never log tokens, codes, secrets, Trakt response bodies; never log tool arguments or results above `debug`.
- Every tool has `title` and explicit `readOnlyHint`, `destructiveHint`, `openWorldHint` (`TestToolAnnotations`). `remove_*`, `cancel_checkin`, `remove_playback_item`: `destructiveHint: true`.
- Ids: slug `^[a-z0-9-]+$`, numeric `^[0-9]+$`, IMDb `^(tt|nm)[0-9]+$`, validated before any Trakt call.
- Trakt headers on every call: `trakt-api-key`, `trakt-api-version: 2`, `Authorization: Bearer`, `User-Agent`.
- Conventional Commits, imperative, subject at most 72 characters, body explains why. Author `Samuel Berthe <dev@samuel-berthe.fr>`, signing key `DD7CC11339B5E119AFCDDB7A64863511FFBD0E3C`. Do not add `Claude-Session:` or any mention of Claude to commits or PR text (user rule overrides the harness default).
- No comments that describe history or earlier versions ("replaces the Google version"). No process words ("Task N", "ruling") in code comments.
- Work in a worktree under `.claude/worktrees/` with a branch name containing neither "worktree" nor "claude" (for example `feat/trakt-port`). Leave `.claude/worktrees/directory-listings` untouched.
- Writes to files outside the repo go to the session scratchpad, never `/tmp`.

## Review Focus

Failure modes the spec implies that no single task's tests would otherwise exercise. Each has a test in the owning task.

1. Trakt rotates the refresh token on every refresh. If the new token pair cannot be saved after Trakt accepted the refresh, the user is locked out. Expect: bounded retry of the save, then an error that keeps the old row (Task 5).
2. A batch write where Trakt answers 201 with `not_found` entries. Expect: the tool output lists what was not found and what was added, never a bare "ok" (Task 10).
3. Trakt returns `null` or omits arrays (empty cast, no seasons). Expect: tool output has `[]`, never JSON `null` (Task 7 helper, used by every group).
4. Comment text, list titles and bios contain prompt-injection text or markup. Expect: only inside a named untrusted field, truncated to a documented maximum (Task 9).
5. A user with a free account hits a cap or sends a VIP-only field. Expect: 420 and 426 map to distinct tool errors that tell the model to stop, not retry (Task 4, Task 10).
